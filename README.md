# About
This simple webpage is an interactive leaderboard for 4 player matches (cardgames like Whist, boardgames like 7-Wonders, etc) with point ranking. The leaderboard handles new player, removing player, freezing leaderboard and updating scores

# How to
In the upper right corner, you can find :
- (R) : Randomise the leaderboard (for initial matchmaking)
- (F) : Toggle freeze (Blue : On / White : Off). While freeze active, the scoreboard won't change until the page is manually refreshed
- (+) : Add a player

In addition, you can either click on a table (Table1 for exemple) to add the score of each player in the current table, or click a player (Like Name1) to update previous scores, add a new one or delete the player
